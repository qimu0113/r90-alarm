## 二、如果你想自己构建

只需要两样：JDK 17–21，Android SDK 35。**Android Studio 不是必需的。**

```bash
git clone https://github.com/qimu0113/r90-alarm.git
cd r90-alarm

# 让 Gradle 找到 JDK（二选一）
export JAVA_HOME=/path/to/jdk-21
# 或写进 ~/.gradle/gradle.properties: org.gradle.java.home=/path/to/jdk-21

# 指向你的 SDK（该文件不入库，必须用正斜杠）
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

./gradlew testDebugUnitTest --rerun-tasks --no-build-cache
./gradlew assembleDebug
```

> ⚠️ **`--rerun-tasks --no-build-cache` 不能省。** 不加的话 Gradle 可能把改代码之前的旧测试报告原样喂回来，给出一个假的"全绿"。判断真跑没跑，比对报告时间戳与源码修改时间。

### 构建期容易踩的五个坑

都是"只有真跑构建才会暴露"的类型：

| # | 坑 | 症状 |
|---|---|---|
| 1 | `build.gradle.kts` 用了 `#` 注释 | Kotlin DSL 只认 `//`，报 `Unresolved reference` |
| 2 | 缺 Compose 编译器插件 | Kotlin 2.0 起它是独立插件，报 `Compose Compiler Gradle plugin is required` |
| 3 | `local.properties` 路径用了反斜杠 | `D\:\Android\Sdk` 被解析成 `D:AndroidSdk`，报错却指向 `compileDebugJavaWithJavac` |
| 4 | 工程路径含非 ASCII 字符 | **不影响 `assembleDebug`，但 `testDebugUnitTest` 会直接失败**（Windows 测试 worker 传不了非 ASCII classpath） |
| 5 | 测试结果假阳性 | 报 `BUILD SUCCESSFUL`，但那是改代码之前的旧报告 |

## 三、如果你想发布自己的版本

这个项目是自用工具，你可以直接 fork 改成自己的。发包前需要处理签名。

### 1. 生成自己的 keystore

```bash
keytool -genkeypair -v -keystore your-release.jks -keyalg RSA -keysize 2048 \
  -validity 10000 -alias your-alias
```

### 2. 在工程根目录建 `keystore.properties`

```properties
storeFile=/path/to/your-release.jks
keyAlias=your-alias
storePassword=...
keyPassword=...
```

该文件已在 `.gitignore` 中。文件不存在时构建**不报错**，只产出 unsigned APK —— 所以别人 clone 下来没有密钥也能正常构建。

### 3. 若改了包名，必须改 `applicationId`

当前是 `com.yanfei.r90alarm`。包名决定"是不是同一个应用"：

> **包名一旦发布就不能再改。** 改了就是另一个应用，已安装的用户无法升级，只能卸载重装。

### 4. ⛔ keystore 的安全边界

| 风险 | 后果 |
|---|---|
| **密钥丢失** | 永久失去对同一包名发布升级版的能力。签名不匹配，系统拒绝覆盖安装，所有用户必须先卸载 —— 对已发布的 App 等同于弃用 |
| **密钥泄露** | 任何人都能签出冒充你的"更新包" |

**所以：备份到至少两个地方，且不要放在同一块物理磁盘上。**（同一块盘上的备份防不了整盘故障。）

**也不建议把 keystore 放进 GitHub Actions Secrets** —— 那等于接受"签名密钥托管在第三方平台"。真要自动化出签名包，自己找台机器跑更稳妥。

### 5. 关于发布 APK

GitHub Release 上传 APK 时，建议同时给出 **APK 自身的 SHA-256**，让别人能核对下载到的文件和源码构建出来的是否一致：

```bash
sha256sum app-release.apk
```
